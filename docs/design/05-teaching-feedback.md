| 用户要求 | 具体实现 | 验收行为 |
|---|---|---|
| ① PDF不收阅读说明/整书导航及练习解答与研究启发；必要说明放返回消息 | textbook的PDF边界、pdf的清单示例、synthesis计划与knowledge-base收录契约；默认不自动生成练习集 | 看实际清单和正文；保留封面目录、必要背景、完整教学算例、证据边界，不能换名把排除内容放回去 |
| ② 自己梳理全文数学逻辑，由浅入深，不受原文顺序约束 | synthesis先存依赖与重排依据；textbook从目标反查依赖，再从已知安排学习路径；deep-read取消固定十一章暗示 | 每个核心结果的前提先就绪，附录可提前；对象→正文反向映射仍覆盖全文，不以重排漏内容 |
| ③ 新事物从问题、直接想法、本文方法与效果引出 | textbook要求新内容的引入链，mathematics落实技术/定理/记号的不同处理 | 连读引入与使用段能理解为什么需要它；自然尝试标教学重建，不编作者研究史；直接方法有效时不捏造失败 |
| ④ 证明细致，写出必要计算，解释对象如何选出 | mathematics细化分块、代入、系数求解、常数选择、存在依据和证明承接 | 核心证明及必要依赖逐项复算，不能以“显然”跳过承重环节；无法补齐时保留缺口 |
| ⑤ 变量使用处自然回顾类型、空间、维数与作用 | mathematics增加使用处解释规则及句式示例，覆盖例子、证明和跨章复用 | 不能依靠末尾索引或生硬初始化清单；空间/维数/约定改变要当场说明，抽象数学按实际结构解释 |
| ⑥ 减少碎小节，恢复逻辑连续性与可读性 | textbook按实质问题/子目标分节，synthesis要求遮住标题连读，quality列碎节阻断项 | 同一推理用段落、过渡句与对齐公式接续；稳定锚点不强迫加标题，无机械章数上限，不删内容换流畅 |
| ⑦ 内化后用自己的话详细严谨讲解 | SKILL主入口与textbook明确重建而非翻译加短评，quality核自写论证能否重建核心链 | 准确陈述与必要公式仍保留，解释计算、动机、条件和边界有实质内容；不能编证据或把修补归给原作者 |

以上要求进入运行规则、入口与默认调用提示；README的能力/输入输出示例和早期设计说明也已同步。
不把所有细节堆入SKILL.md，没有新增Skill运行脚本，也未改变现有自动发现策略。
