# 再次短稿反馈：从专家证明提纲改为可跟读的讲义

2026-11-07。用户反馈46页、16章和8幅数学矢量图仍然不好读，未达到此前提供的四份参考讲义的教学尺度。
这次修订以“读者理解过程是否实际写出来”为主，不继续用章数、图数或规则条数证明可读性。

## 本次重新核对了什么

只读查看用户所指产物中的方案语义、单位与对数格、聚焦舍入、线性计算和复合分解等代表段落，
并查看实际页面；没有重审整篇论文。重新读取四份私人讲义中的代表性教学单元与页面，
比较其如何解释一次计算、展示状态转换、辨析误解和衔接一般结论。
私人原件与提取结果不进入公开项目，公开材料只有自编例子与匿名化方法总结。

发现现有稿件不是完全没有动机、证明或例子，而是很多地方仍太快：
对新工具的定义不等于已教会其使用；一个正确的几行证明可以省掉初学者最需要的理解过程；
复合算符虽有示意图，读者仍需自行拼接每个算符的语义。
“取伴随更简洁”之类专家捷径会在难处再次增加先修负担。
原计划甚至记录了低于百页规划的复审，但以增补数章和对象证据自查作为结束，未真正校准难段的解释尺度。

## 实现变化

| 要修复的行为 | 当前实现 |
|---|---|
| 概念名与公式齐全，仍听不懂 | 新增[讲解尺度](../../skills/math-research-reader/references/teaching-style.md)：解释对象怎样变、为何这样做、式子说什么、怎样接入目标 |
| 只给“由标准操作即得” | 陌生操作先实际演示；复合式追踪一个元素/坐标，再一般化；新操作不能因证明更短而直接跳过教学 |
| 例子只是证明后的装饰 | 自编[完整讲解单元](../../skills/math-research-reader/references/examples/adjoint-walkthrough.md)：从错位记录到对齐、伴随、左逆、最小二乘、投影与边界，数值过程和一般证明相互对应 |
| 只用简单背景例验证可读性 | 完整精读先选论文真正承重的难单元校准，基础小例不能替代后半本复杂证明；校准尺度持续用于全书 |
| 计划百页，成稿仍自动缩短 | 百页级要求落实到实际教学工作量，不能仅以加数章、加图和覆盖表豁免显著压缩；按具体理解障碍重写整个单元 |
| 自查通过与用户体验混同 | 具体理解问题只依据正文回答并补回正文；自查和读者反馈分记，用户否定相关可读性后旧教学pass失效 |

入口、默认提示、成稿计划、数学讲解、长篇规范、知识库和质量规则都链接这一套尺度，
没有新加运行脚本、自动可读性分数或固定章节模板。
此前排除导读/练习附录、连续叙述、变量自然引入、完整证明和多幅数学矢量图的要求继续有效。

## 追加反馈：几何图解与通式不可缺席

用户指出几何矢量图仍少，连续公式影响阅读；低维例必须同时给通式。
本次取消“全书至少三幅”的数量暗示，改按每章实际的对象、变换、构造、投影与误差机会持续配图。
知识算例及数值图须接回一般表述、变量对应、条件和简化边界；不能以算例或示意图代证明。
同步修改图示、讲解、数学、计划和质量规则，并在完整讲解样例中加入四幅自绘矢量图，
补足标量伴随和一般列变换恢复的通式。实际构建与局部复算见
[图解与通式验证](../../evals/results/visual-generalization-validation.md)。
此追加没有重新精读整篇论文；先前无图的5页样例验证保持其原快照范围。

## 再次强调：最少必要章节与原位深化

后续用户明确偏好尽量少的章节和连续论证。本次将它落实到整书计划、写作队列、补写位置和验收，
默认少量主章、必要的大转折才分小节，不用三级以下标题；文件/内部对象不自动成为可见章节。
新增知识沿当前困难、自然尝试的局限、本文方法与效果引出，不把这些维度打印为模板小节。
缺页数时在首次需要处补齐背景、计算、图例和证明，并重写过渡；禁止书末添补课章凑页。
随包完整讲解例合并五个小节并补上问题承接，194个数学节点及四幅图保持。
实际用两份续写文件组装为一个可见主章，正文Span锚点的跨文件定位正常。
