# 90页、十章与首次完整成稿验证

2026-11-08。修改整个Skill的默认课程组织、写作及导出流程，适用于任意新论文，
不是给某一篇旧精读结果补章节。本轮未生成新的整篇教材。

## 当前行为

- 完整精读有效教学正文至少90页，可见主章至多10章；书目、附录若自成主章也计数。
  正常A4/11pt排版，不以空白、重复、装饰图或放大字号计入有效正文。
- 首次写作前将全部对象、必要先修、证明子目标、算例及图解机会安排进完整课程蓝图，
  按百页级教学细度直接展开。正常流程不先输出短整书，再根据页数反复补到门槛。
  页数是最终异常检查，不是写作目标函数；意外不足时回查真实教学缺口并原位融入。
- 新对象沿当前困难、自然尝试、实际方法和效果引出；变量在使用处自然交代类型、
  空间/维数、范围和作用，承重推导包含可复算中间步骤。例子必须接回通式及适用条件。
- 图解随课程蓝图规划并在相关推理处绘制，几十幅或更多均可；逐机会检查，
  不把全书已有图数作为停止理由。共享数据、坐标和风格，逐图核其数学关系和标签。
- state维护首次稿的planned、composing、content-reviewed状态。前两种状态阻止完整精读
  整书导出，且在工具链探测前停止。状态不是质量认证，内容、公式、图示与最终全部页面仍须核验。
  未含该字段的旧工作区保持兼容，但不豁免当前90页和十章检查。

## 程序与实际工具验证

在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -B -X utf8 -m unittest discover -s tests -v
```

52项中51项通过，1项因Windows不允许测试符号链接而跳过。覆盖以下行为：

- 模拟编译产物89页拒绝，90页通过物理页门槛；失败保留先前成稿。
  这些边界测试不证明有效正文、数学内容或视觉质量合格。
- 实际Pandoc标题结构10章接受、11章拒绝；分批文件数不当作主章数，原始TeX章节命令不能绕过。
  最终目录与是否把独立章节伪装为小节仍需人工核对。
- 历史70/71页契约继承当前90页门槛；普通input、book模式及状态继承不取消门槛。
- planned/composing在完整整书导出前停止；content-reviewed仍需通过实际页数门槛。
- 缓存定位按字面量忽略大小写查找，返回限定数量的位置及限长片段，明确报告未回传的结果；
  完整取页不因定位输出限制而被截断，定位不会重新调用提取器。

more_matches为true，不回传整页文字。定位后仍需读取完整阅读单元并核原页公式与图。

官方quick_validate.py分别检查项目Skill与用户安装入口；入口为指向项目源码的目录联接，

## 额度优化的范围与限制

定位工具减少不相关文字回传；计划合并重复的课程字段，用已有对象ID和正文锚点引用，
不在JSON重复复制证明。规则按需加载、完整单元一次取页、正文仅存唯一Markdown、
共享背景及图形约定、合并同单元检查、只重查变更依赖、不反复编译短稿，减少重复工作。
不删教学正文、证明或最终逐页核查，不默认额外agent或付费服务。

本轮没有测量实际账户用量，不承诺固定省额比例，也未以同条件整本教材对照验证最终效果。
未进行独立初学者实验；单测、结构检查与规则更新不证明第一份整书已达到百页或读者一定能学会。
构建器只能核物理页数和标题结构，有效教学页数、内容深度与美观另行验收。
早期评测保留原日期、门槛和验证范围；本轮未改用户论文、提交、推送或更新GitHub发布。
