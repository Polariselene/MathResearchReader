## 测试材料与实际结果

测试使用[自编教学单元](../fixtures/first-year-depth/lesson.md)，以相关本科代数和线性代数为基础，
不假定读者学过多项式商环、槽表示、单位舍入或对数单位格。
它只处理一个四维代数中的二维子代数，不是一篇32页研究论文的替代报告，
也不是百页整书压力测试或完整加密方案验证。

正文围绕同一个消息$(1,0)$和尺度$10$推进，实际补写定义、动机、表示转换、逐步乘法、
一般误差恒等式、确定性界、失败主张的反例与一维近点证明，而非把数学对象列出后批量标完成。
用现有`build_pdf.py --book`实际构建成8页中文数学PDF，四幅图已嵌入。
8页仅是这个限定教学单元的长度，不是完整论文的目标篇幅或通过门槛。

| 教学义务 | 正文证据及核查 |
|---|---|
| 陌生对象从基础接入 | 第1节说明等价类、唯一代表元、乘法降次、整数格与实空间、二维切片；证明$t^2=2$及子代数封闭 |
| 空间、维数与变量自然出现 | 第1–2节区分$R,S,T$和实二维槽；由两个标量方程解出逆映射，不把全四维空间画成实二维 |
| 完整算例连接一般结论 | 第2–3节逐项计算普通舍入、预变换、系数取整、乘回单位、两槽解码与误差；证明一般误差恒等式 |
| 前提与边界独立解释 | 第4节从三角不等式证明四维界，再给二维收紧界；尺度8给出相同输出，驳斥“每个输入都严格改善”的额外主张 |
| 不跳过证明 | 第3节证明乘单位双射保整数格；第5节从最近整数逐步推出对数覆盖界，不声称一般数域单位格定理已证 |
| 图真正承担数学解释 | 坐标基与映射、两次舍入格点、确定性误差可行域、对数近点，四种不同任务；每幅图前后都有读图和适用边界解释 |

这是同一上下文对完整局部单元的自查，不是独立数学审查或读者学习实验。
没有把数值检查升级为一般证明，也没有把该单元通过升级为整篇论文通过。

## 计算与矢量检查

- 用`Fraction`精确检查四维负循环乘法中的$t^2=2$和$(t-1)(t+1)=1$。
- 用60位`Decimal`复算尺度10、8的完整算例，误差恒等式数值差小于$10^{-55}$，并核对二维界。
- 对数例选$k=2$，最大坐标差约$0.456893$，不超过$0.635777$；另做2000个固定随机种子的算术检查。这些有限检查不替代正文证明。
- 四份原始[TikZ源](../fixtures/first-year-depth/figures/coordinates.tex)及同目录其他源均用XeLaTeX编译。
  每份图形PDF均有矢量路径、没有栅格图像资源；逐幅实际查看标签、箭头、坐标和可行域，
  修改可行域图的绘制顺序后重新编译并复查。
- 最终PDF逐页渲染并查看全部8页，图分别在第3、5、6、8页；中文、公式、图注、页码和内容没有可见缺失或裁断。
  最终PDF全部页面无栅格图像资源，图和文字保持矢量。路径数量本身不被当作教学质量证明。

数值、资产、最终PDF、逐页检查与包文件哈希见
[first-year-depth-checks.json](first-year-depth-checks.json)。派生整篇PDF、渲染图与编译中间文件
仅保留在被忽略的`.local-test/first-year-depth/`；四份小型图形PDF是有明确源的公开测试资产。

```powershell
.\.venv\Scripts\python.exe -B -X utf8 .\skills\math-research-reader\scripts\build_pdf.py --root .local-test/first-year-depth --book book.json --output exports/lesson.zh-CN.pdf --pandoc .\.venv\Lib\site-packages\pypandoc\files\pandoc.exe --replace
```

`--replace`用于本次图形修正后的重新构建。官方`skill-creator/scripts/quick_validate.py`
对修改后的Skill目录返回`Skill is valid!`；同时检查YAML展示信息、相对文件链接、
数学节点在Pandoc组装中的保留和唯一运行脚本约束。
包结构、链接和构建检查不自动判断数学或教学效果。

构建器实现及版式模板未修改，故未重复运行既有22项单元测试；README中的21通过、1跳过保留其既有范围。
