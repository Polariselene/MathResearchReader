# 首次整书反馈后的Skill修订验证

2026-11-06。任务是落实用户七项反馈，更新Skill，而不是本轮重写旧83页PDF。
修改记录见[逐项对照](../../docs/design/05-teaching-feedback.md)，成稿行为见[两段局部改写](narrative-teaching-sample.md)。

## 自查到的实际变化

旧规则同时要求连贯讲解、固定十一部分，并允许把导读与练习集中解答收入PDF。
本次取消固定目录的暗示，将覆盖清单、内部八阶段与PDF正文目录分开；
把新对象动机、变量使用处回顾、承重计算和连续叙述写进计划、成稿与阻断验收，
同步修改PDF清单示例、知识库契约、默认提示、README和旧设计说明。

| 七项反馈 | 局部检查证据与范围 |
|---|---|
| PDF收录边界 | 规则示例不再列guide；真实Pandoc组装的正文清单只列数学样例，单独保留的导航、练习和研究建议不进入派生AST；必要数学公式仍保留 |
| 依赖驱动重组 | 线性系统样例先说明精确求解失败，再从最小二乘目标推到SVD、伪逆及投影修正，而非先报原式再附短评；全文依赖重排规则已改，但新整书次序未验证 |
| 新对象动机 | 两段分别由欠坐标无解、逐坐标缩放不能消相关引入工具，并解释效果与未解决边界；未把自然尝试编造成作者研究史 |
| 证明与计算展开 | 样例写出正交分解、最小范数选择、残差展开、联合零空间证明及白化矩阵逐项乘法；一般结论由正文论证，数值仅复算实例 |
| 自然引入变量 | 响应矩阵、系数、观测、SVD块及协方差在运算前用句子交代空间、维数和角色；转换到新例时重新说明，没有专设初始化列表 |
| 连续性 | 线性系统从失败到工具到推导再到过猜条件连续展开；两段仅按实质数学问题分节，没有为每个公式、例子或证明另开标题 |
| 内化解释 | 自写论述解释伪逆为何出现、投影为何保留、假列为何须联合独立，以及逆平方根如何由特征方向归一化推出；必要准确公式保留，不是原文摘录加点评 |

以上是同一上下文对实际样例的自查，有明确范围，不是独立评审或读者可读性实验。
完整性审计仍逐个检查核心对象，不能靠两段样例推论全部未来论文都能讲好。

## 可重复检查

实际执行记录、样例与包文件哈希见[narrative-teaching-checks.json](narrative-teaching-checks.json)，
官方结构校验输出见[narrative-quick-validate.txt](narrative-quick-validate.txt)。
检查覆盖：实际清单与Pandoc AST组装、数学节点保留、局部示例的精确算术/SVD/白化复算、
运行规则及README等文件的相对链接、YAML与现有调用策略、唯一Skill运行脚本。
结构与数值检查不能自动判定叙事质量。

本轮执行结果：上述检查均通过，官方输出为`Skill is valid!`；实际清单仅收数学正文，
136个数学节点按原顺序完整保留。遗漏坐标例的精确系数为3、残差为(8,−4)，
另核三种秩情形的最小范数性质、联合满秩与相关列失败例、白化及奇异投影例。

构建器与PDF版式代码未修改，因此没有为文字规则添加字符串断言测试，
也没有重复执行未改变的22项构建器单元测试。已有测试记录保留其原时间与范围。

没有生成或渲染新的PDF，没有更改用户D盘中的旧成稿，没有执行作者实验、独立多agent审查、
Lean或学习效果测量。旧83页产物不能被记作修订后新版Skill的整书验收；
下一次完整精读需按新规则重新组织、写作并连读和逐页检查，才能评价整书改进效果。
