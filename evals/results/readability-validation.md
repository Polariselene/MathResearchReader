## 实际对照范围

重新读取四份私人讲义的代表性单元，并分别查看实际页面，覆盖局部仿射递推、
从观测列方程与消元、双轨搜索的变量状态、商环计算与表示转换。
另只读查看46页产物中的方案语义、单位/对数格、聚焦舍入、线性运算、复合分解等代表段落与页面。
没有逐页数学认证四份讲义，也没有重新审查原论文全文。
具体私人原件、定位和提取文本只在被忽略的本地目录，不随项目发布。

主要发现是：已有例子、定义、中间公式和矢量图仍可能组成一份专家证明提纲。
以“原式—几行推导—一个例子”检查齐全，不保证读者理解每一步的具体动作与作用。
需要把一次理解过程写完，并用真正难的单元校准，而非再次测试一个基础概念。

## 完整自编校准单元

新[讲解样例](../../skills/math-research-reader/references/examples/adjoint-walkthrough.md)
是原创数学案例，不复制私人讲义或原论文内容。
从同一份三维数据的两列错位记录开始，依次解释对齐、收集贡献、复内积、伴随、
一般循环移位、左逆、最小二乘、正交投影与失败边界。
它针对“取伴随即可”这类陌生操作的教学缺口，仍不是原论文完整复合分解证明的替代物。

以下问题在自查时只依据已经写入正文的内容回答，不以检查者本来会的知识补台。
这是同上下文的文本自查，不能称为真实初学者实验。

| 实际理解问题 | 正文中的答案与依据 |
|---|---|
| 为什么不能把两列直接按行平均？ | 第1节具体算出两列为$(2,-1,3)$与$(3,2,-1)$，同一行的数来自不同输入坐标；直接平均得$(2.5,0.5,1)$而非输入 |
| 为什么反向移位，而不是再正向移位一次？ | 第1节逐项移回第二列得到原输入；第2节展开内积后按$x_0,x_1,x_2$重排，显示每项贡献应读取哪个位置 |
| 伴随为何是求和，它为何不是逆？ | 第2–3节从内积定义推导反向对齐求和；再算$B^*B=rI$，说明还要除以$r$才有左逆 |
| 为什么复数时必须共轭？ | 第2节通过$A:x\mapsto ix$逐行算出$A^*:y\mapsto-iy$，并解释置换矩阵只是一个特殊情形 |
| 三维例子如何推广到任意维数？ | 第3节明确$i,k,j$的关系，给出模$d$的完整换元，再对各列求和；没有只写“同理” |
| 任意两列平均后能恢复“真实输入”吗？ | 第4节给出不相容矩阵，实际计算平均与重新编码，输出不等于原记录；未假定存在真实输入 |
| 为什么平均是最小二乘解？ | 第4节将误差移回同一坐标，展开平方，指出交叉项因零和关系消失，剩余项只在均值处最小 |
| 投影丢掉的部分与什么正交？ | 第4节证明$B^*(Y-PY)=0$，因此与所有相容编码$Bx$正交，并复算具体残差 |
| 为什么第二列带缩放后不能照搬除以2？ | 第5节直接算出$\widetilde B^*\widetilde B=\operatorname{diag}(5,2)$，输入$(1,1)$恢复成$(2.5,1)$ |
| $1/\sqrt r$是否自动意味着噪声降低？ | 第5节证明确定性界，再给$e_j=R^jv$的等号情形，指出各列误差对齐后相同，平均不消失 |

上述核心问题的解释均已落在唯一正文中。一般数学结论由正文证明，有限数值检查只复算算例。
自查认为这个限定单元符合新讲解尺度；读者实际能否理解仍为unverified。
这一判断不能扩张为整书可读性通过。

## 实际构建与计算

将随包样例复制到忽略目录，建立仅收该单元的`book.json`，使用现有构建器的`--book`路径，
实际生成5页中文数学PDF。逐页渲染并查看全部5页，矩阵、共轭、分式、求和、换元、
一般证明和反例未发现可见裁断或缺字。
这5页是一个限定核心教学单元，不是整篇论文；不是按页数判断通过，也没有使用机械填充。
本轮没有新增图形或运行脚本，多幅数学矢量图的整书要求仍保留。

执行记录包括：

- 完整复算三维编码、对齐平均、不相容记录、正交残差及缩放失败例。
- 5种$(d,r)$、每种12次复数算术检查，覆盖$r>d$的循环重复情况；核伴随内积恒等式、左逆、
  投影幂等、残差正交、最小二乘展开及确定性误差界。
- 核对相关误差例达到界，未将重复记录解释为必然降噪。
- 用实际Pandoc解析与组装检查数学节点顺序保留，结构检查不能判定教学效果。
- 运行官方`quick_validate.py`、检查YAML、相对文件链接、唯一运行脚本约束及改动中的空白问题。

命令运行使用README已记录的Windows/Python/Pandoc/TeX工具链，未安装新工具。
本次实际的导出命令为：

```powershell
.\.venv\Scripts\python.exe -B -X utf8 .\skills\math-research-reader\scripts\build_pdf.py --root .local-test/readability-calibration --book book.json --output exports/adjoint.zh-CN.pdf --pandoc .\.venv\Lib\site-packages\pypandoc\files\pandoc.exe
```

`.venv`是本机已有工具位置，不是项目分发的依赖；命令只导出已经写好的正文，不自动精读论文。
官方结构校验返回`Skill is valid!`。构建器和版式未改，未重复运行既有构建器单元测试。
数学、组装、最终PDF与当前Skill文件哈希见[readability-checks.json](readability-checks.json)。
PDF与页面图片留在被忽略的本地目录，不纳入公开清单。
