## 五类教学案例自查

完整推导见[小案例](reference-report-teaching-cases.md)，实际数值输出见
[原始复算数据](reference-report-numeric-checks.json)。使用Python标准库Fraction、math、cmath
执行内联复算，没有随包新增测试运行器或数学验证脚本。

| 案例 | 检查结果 | 能证明的范围 |
|---|---|---|
| A 独立观测与比例类 | 非零2阶子式、候选零向量、第三行线性关系逐项核对 | 指定点集的秩与解族；一般解释见正文代数推导 |
| B 二分不变量与目标偏移 | 8步保持两端状态；a=0.6484375，h=0.00390625；目标误差0.0484375 | 指定单跳变oracle上的轨迹；一般不变量/误差由正文证明，不验证论文几何模型 |
| C 谱隙与扰动 | 同η=10^(-8)，σ=1时sin角=10^(-8)，σ=10^(-8)时约0.7071 | 自编矩阵两组数据；一般2η/σ界由正文说明 |
| D 统计转换 | 精确有理数核对Cov=-1、和方差0；比值期望2/3与期望比1/2 | 两个有限分布反例；不否定附有充分条件的定理 |
| E 共轭与代价 | 4个实数x复算残差均小于10^(-14)；任务图深度4、工作量6 | 复数数值抽样和自编依赖图；恒等式另有符号推导，不证明任何密文实现 |

这些案例是规则的具体示范与同上下文自查，不是独立代理执行、真实文章端到端评测，
也没有把反例来源冒充为用户讲义或原论文。未执行私人PDF中提及的verify.py。
