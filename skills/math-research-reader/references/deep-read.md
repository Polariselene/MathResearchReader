# 完整教学级精读

先实际读取正文与附录，登记章节、定义、符号、假设、公式、引理、定理、推论、证明、
图表、算法和实验，包括无编号关键对象。每项记录核心性及理由、位置、状态和正文链接。
主结果依赖的定义/引理纳入核心；非核心说明作用与取舍，不能批量降级规避覆盖。

| 阶段 | 工作与产物 |
|---|---|
| 1 文献定位 | 身份、版本、背景、问题来源、全文与附录清单、阅读计划 |
| 2 研究逻辑 | 问题→旧方法限制→洞见→设计→证据；研究思路图 |
| 3 数学准备 | 定义、公理、对象、全局/局部假设、符号、先修知识 |
| 4 核心方法 | 输入、步骤、中间状态、输出、复杂度/代价、机制例子 |
| 5 定理精读 | 准确陈述、量词、强度、范围、关键引理、依赖图 |
| 6 证明重建 | 每步目标/前提/理由、中间公式、补充推导、例子和直觉 |
| 7 严谨性审计 | 原证明、引用、反例、边界、漏洞及其影响 |
| 8 研究启发 | 贡献比较、最脆弱假设、局限、可检验方向、未解问题 |

阶段可迭代并保存checkpoint；写完不等于通过。第5–7阶段按
[数学教学](mathematics.md) 与 [审计](proof-audit.md) 严格执行。
阶段1–3按 [来源阅读](source-reading.md) 解析宏、计数器和完整单元；阶段4–6形成
[写作计划与主张证据对应](synthesis.md)，实际核对后再成稿，不从标题/抽取摘要直接写完。

原先十一部分改为内部覆盖维度：身份、研究问题、作者思路、必要背景、方法、
公式、证明、贡献比较、证据与局限、术语与来源等逐项有处置，不要求各自成章。
PDF按全文数学依赖和读者理解路径重组，必要实验与审计依据接入相应论证；无定理不造定理。
阅读说明、导航、练习解答与额外研究启发默认移出PDF，必要信息在交付消息说明；
第8阶段仍检查贡献与边界，但工作阶段不自动成为PDF章节。
审计发现独立维护，主报告链接；不维护两套独立证明。
按 [教科书级规范](textbook.md) 组织连贯讲义。采用导航/机制重建/
证据核验三种阅读视角贯穿八阶段：先浏览只用于建立地图，随后必须逐单元读完原文及相关附录，
最后回查摘要和结论有没有超出已建立的证明或实验，不把“看过三遍”当作理解的证据。

贡献比较按 [文献关联](literature.md)，不能把作者自称创新当成已核实首创。
交付知识库和中文PDF；只有Markdown、PDF受阻时明确交付未完整。
可在诚实报告中保留论文自身未解问题；核心内容未读或未解释则不能宣布精读完成。
