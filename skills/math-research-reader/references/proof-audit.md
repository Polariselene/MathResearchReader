# 严格证明审计

定位指定版本、定理及完整证明，收集定义、全局假设、引理、附录与直接外部依赖。
编号不存在时报告索引结果并澄清，不用近似结果冒充。默认Markdown，明确要求才导PDF。
先重建原文推理链；教学补齐另标[数学重建]并保留原文省略及补齐条件。
按 [数学教学](mathematics.md) 核对公式与命题。
依本次对象读 [专门证明义务](proof-obligations.md) 对应部分，检查分析、概率、PDE、
几何/代数或离散条件；反例策略与全称/存在/唯一/一致/几乎处处的逻辑目标匹配。

## 检查维度

- 定义良好、存在性、类型/维数、域/值域、符号。
- 明示/隐藏假设、全局/局部、必要/充分、实际命题强度。
- 量词顺序与依赖、逐点/一致、有限/无限、概率空间与事件。
- 等式/不等式、估计方向、分母非零、可逆性、交换极限/积分/求导/求和的条件。
- 引用准确陈述、参数与假设映射、循环依赖、跳步、缺失依赖传播。
- 低维、零值、空集、退化、端点、极端参数、有限样本/渐近。
- 假设删弱、结论加强、最脆弱条件、反例与sharpness。
- 证据证明原命题、较弱命题还是不同命题。
- 公式文字层出现疑似符号/括号错误时，先核实际页面再列缺陷；记录排除的提取误读，
  不让丢失绝对值、嵌套偏置或表格脚注变成误报。

每条发现记ID、类型、严重程度与理由、位置、目标命题、原推理、精确问题、
完整数学依据、下游影响、建议修补及额外前提、状态/证据、置信理由、未决项。
区分 mathematical-error/proof-gap/reference-unverified/incomplete-check/exposition/typo。
严重程度取决于数学影响。

反例逐条满足目标假设并计算结论失败；去掉假设后的反例仅说明其重要性。
有限数值试验和找不到反例不是一般证明。报告搜索范围。未获取关键引文时受影响推理链
标unverified，不能只在书目尾备注。修补后成立不表示原文已经证明。

报告顺序：范围—准确命题与前提—依赖—逐步核查—发现—边界/反例—修补—未验证。
可说声明范围未发现问题，不能称形式证明证书。同上下文复查称自查；真实独立执行才称独立，
不要求多agent。计算/Lean只报告真实执行的输入、命令、日志与检查范围。

## 六轮审查与覆盖记账

在八阶段精读的第7阶段或专项审计内部，依次执行以下六轮。它们是本Skill内部工作，
不依赖六个外部Skill，也不自动启动其他agent。每轮保存已检对象、未检对象及数学依据。

| 轮次 | 对象与保留内容 |
|---|---|
| map | 原文实际主张、未编号承重断言、定义、假设、引用使用、计算义务与依赖 |
| references | 每次引用所需外部结果、版本/约定、逐项假设、从来源到当前结论的过渡 |
| proof | 原文每步证明义务、成立依据、补全/缺口，含无问题的困难步骤 |
| stress | 主要及支撑结论的低维、退化、端点、反例尝试与搜索边界 |
| computation | 代数、估计、渐近、计数和数值义务；区分精确/认证数值/探索浮点/模拟 |
| closure | 从声明和原证明重查主张是否建立；核接口、循环、下游影响，最后与既有发现对照 |

专项只作用于目标及必要依赖，不扩成全文审查。完整精读则覆盖全部核心及其依赖，
非核心取舍保持可见。新发现义务回填map及受影响轮次，不能只统计已检查对象来缩小分母。
缺工具、难证明、没时间、来源不可达都不是not-applicable。

.mrr/audit.json记录schema_version=1、输入快照、声明范围/排除项、每轮
scope_ids/reviewed_ids/status/evidence/reason、findings和independence。
轮次status为pending/completed/blocked/not-applicable；completed表示实际检查完该轮范围，
不表示没问题。finding另记open/resolved/dismissed及resolution_evidence。
同一根因可合并但保留所有位置和依赖；不同根因不能为缩短报告而混为一条。

## 分类与关闭发现

推导错误不自动证明定理为假。区分“该步不合法”“论证缺支撑”“命题有反例”。
能补齐的省略只有在写出有效重建后才归exposition；缺少承重论证仍是proof-gap。
怀疑和没搜到原文不是虚假命题的证据，记问题或未验证，不凑错误数量。

建议修补不等于resolved；只有实际采用的改动/新取得证据与相关证明及下游复查记录才能关闭。
dismissed须给原文/数学依据，不能投票决定。记录修补增加的假设、减弱的结论，
不把“改了命题”藏在文字润色中。

结论同时呈现snapshot_current、coverage_complete、open_defects、unverified_obligations、
independence。输入已变先标stale；发现错误且仍未查完时同时报告“发现问题”和“覆盖不完整”。
无独立过程则closure为自查，independence=unavailable，不伪造独立审查或因此停止其他工作。
需要独立审查时，仅在已有授权和宿主能力允许时执行；交给审查者源、宏、范围与中性外部
定理证据，不提前传旧判决、修补和反例答案；记录实际独立性，不能暗示必为不同模型。
