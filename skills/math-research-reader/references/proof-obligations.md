# 按数学对象选择证明义务与压力测试

只加载本次结果真正涉及的部分。以下检查服务于[教学](mathematics.md)和[审计](proof-audit.md)，
不是要求每篇论文完成所有学科清单。写实际推理与计算，不只给“通过”标签。

## 分析与泛函分析

写清收敛的空间/拓扑及模式；极限、积分、求导、求和交换逐项给支配、一致性或适用结果。
有界、预紧、紧、弱紧不同；子列收敛不推出原列收敛，非可数参数的同时成立也不能仅靠
可数对角子列。延拓需范数控制与目标完备，近似对象须保持约束。

检查具体函数空间、半范数/范数、等价类、对偶、嵌入的维数/指数/端点；弱收敛下乘积和
非线性过渡需额外理由。算子须有真实定义域、值域和有界/闭性条件，形式逆/伴随不自动存在。
可用集中尖峰、平移逃逸、高频振荡、临界奇性测试实际缺失条件，逐项验算空间成员资格。

教学反例：在(0,1)上$f_n=n\mathbf1_{(0,1/n)}$逐点趋于0而积分恒为1。
它只否定无额外条件的极限积分交换；不能反驳明确假设可积支配函数的定理。

## 概率与随机过程

核可测性、所用sigma代数、条件期望版本、可测/可预测选择、过滤与停止时刻条件。
区分几乎处处/概率/分布/$L^p$收敛，换期望需可积性或一致可积等实际条件。
相同分布不表示同一概率空间上的逐点相等，零协方差不代替独立。

“每个参数在某个概率1事件上成立”不推出“存在统一概率1事件对所有参数成立”。
压力测试需尊重零测集：一个例外点不能反驳几乎处处主张，必须说明失败集大小。
例如U在[0,1]均匀，$X_t=\mathbf1_{\{U=t\}}$；每个固定t都有$X_t=0$几乎处处，
但对每个样本取t=U便有$X_t=1$。这定位非可数参数同时化所需的额外正则性。

## PDE、变分与动力系统

区分经典/弱/mild/分布解，明确转换条件；核边界/初值、迹、区域正则性、分部积分边界项。
先验估计不是存在性构造，局部存在不是全局存在，唯一性限于声明解空间。
核椭圆性/强制性、交换子、Sobolev指数、正则化参数一致常数、约束与质量在取极限后是否保留。
bootstrap每步列输入和提升结果，不能假设目标正则性。显式解作测试时同时验证完整方程、
边界和初值，不能只代入其中一部分。

## 几何、拓扑与代数

局部到整体须核重叠相容、定向、连通、完备/紧性；构造是否依赖坐标/代表元/任意选择。
商空间/商环/商模先证关系与映射良定义，再证分离性/光滑/核像/单满等独立结论。
记录域特征、交换性、单位元、有限性、整环/代数闭等假设。消去、除法、对角化、分裂、
张量正合都要各自条件；零因子、挠元、稳定子、重复特征值提供适用的边界例。
交换图说明每个顶点对象、箭头类型、复合方向及为何交换；图形外观不能证明交换。

## 离散、数论与逻辑目标

检查归纳起点/范围、递归良基性、计数重数/标号/对称、划分是否穷尽且不重叠、
求和端点、同余模数、可逆元和例外素数。仅在完整有限集合上穷举才称该有限问题穷尽。

| 被检主张 | 反驳需要什么 |
|---|---|
| 全称 | 一个满足全部假设且违反结论的对象 |
| 存在 | 一个合法输入，使所有候选均失败；某一种构造失败不够 |
| 唯一 | 两个在声明等价关系下仍不同的合法解 |
| 一致估计 | 允许参数族中所需量无界，明确常数不许依赖哪些参数 |
| 充要 | 分别核两个方向，不能只证必要或充分之一 |
| 最优 | 在允许类内达到/逼近界；类外失败只说明条件作用 |
| 泛性/几乎处处 | 按声明的拓扑、测度或范畴验证失败集足够大 |

假设自相矛盾导致的真空命题不是数学反例，另解释其意义。限值对象若不再满足假设，
不能把其失败当原命题错误。候选修补经有限测试未失败仍需证明和下游复查。
