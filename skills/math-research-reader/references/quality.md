# 质量门槛

完整精读按[通用交付契约](delivery-contract.md)验实际PDF与有效正文：二者均至少90页。
全书可见主章不超过10，核真实目录/标题及其数学组织，不只检查文件数或隐藏后的目录。
另核首次写作路径：完整课程蓝图先于正文，知识、证明、图示在所属位置充分展开；
“先做短版再不断补到90页”不是合格默认流程。达到90页但体系是后补拼接的，教学连续性仍不通过。
记录教学正文页范围、排除页及理由、实际页数、哈希与逐页版面检查；不能只填估计页数。
核首次课程蓝图的对象/证明/图示映射与首稿展开是否一致，而非仅核一个提前填好的状态值。
不足则length检查fail并继续写作，不能靠coverage/pass或“短文无需长讲义”抵消。

分别验收文献理解、数学理解、证明审查、文献关联。长度、美观、脚本成功不代替正确性。
检查记pass/fail/unverified和依据；不适用记applicable=false与理由，不算通过。

完整性与数学自检：

- 真的读取声明范围完整正文、重要附录及补充了吗？
- 核心章节/定义/公式/定理/依赖引理有登记、展开吗？非核心有作用与取舍吗？
- 假设、量词、维数、符号、关键推理已核对吗？公式有中间推导吗？
- 四来源标签分开吗？有没有把猜想当定理？
- 来源标签之外，恒等式/条件命题/近似/模型/启发式/实验的性质分清了吗？
- 关键引文取得原结果并验证条件了吗？证明链未闭合与影响是否明确？
- 边界/反例实际检查了吗？有用可视化生成并解释了吗？

未读/未解释核心阻止完整精读完成。原论文漏洞不阻止诚实审计报告交付，但阻止宣告
相关定理已验证；关键依赖未知则下游unverified。

## 深度不是对象覆盖率

对每个核心对象单独核对并保存正文落点：读者需要的专题背景是否实际讲完，
引入动机能否跟上，必要公式/证明是否逐步可复算，例子是否走完中间状态，
边界是否解释，图解是否帮助读者理解该步骤。不适用项给具体理由，不能批量填“已说明”。
read/explained/audited全为true只证明相应记录存在，不能据此自动推出教学深度通过。
“全部编号对应九章”“已有推导和例子”或PDF编译/逐页排版通过均不足以作为深度验收依据。

教学欠缺未清零时depth检查fail，整书仍为阶段稿；原论文真实未闭合结果则如实保留
数学状态与影响，不能补造证明。把两种情况分开，不能用论文有疑点掩盖讲义省略。
缺关键引用证明时准确说明依赖及条件，相关全链验证保持unverified；仍要讲清可教部分。

长篇检查另记录reader_profile、每章教学义务及完成证据、原文/正文页数与压缩复审、
多幅数学矢量图的作用和验证。对需要专题补课的多结果研究论文，若正文比原文更短，
不得直接宣布完整教材完成；依据textbook.md回查并继续补写。
达到百页也不会自动通过：页数、背景深度、证明细度、图解和数学正确性分别核。
逐章查有用几何图解是否实际落实，不以全书已有几幅矢量图通过局部缺图；
查连续公式是否解释了对象与操作、图是否真在推理中使用，而非最后集中放图。
知识算例须核通式/一般命题、变量与参数对应、条件和简化边界；只有数字或小图而没有一般结论不通过。
一般结论须有相应论证或准确依赖，不能从一个特例臆推；反例与修补范围另核。
进一步按[讲解尺度](teaching-style.md)核难单元：具体理解问题能否仅从正文回答，
复杂式中的对象如何移动、为什么取该操作、所得结果如何使用是否真讲清。
“已补中间公式”不等于解释已完成，基础例自查不能代替核心复杂证明的可读性校准。
用户已明确指出“不懂/太压缩”时，相关旧教学pass失效，重新打开具体缺口与下游段落；
不能以此前自查或新增图数反驳读者反馈。未补回正文前教学检查不通过。
分别记录teaching_self_review与reader_feedback；没有实际读者反馈则后者unverified，
这不强迫等待用户逐章批准，但禁止将模型自查称为用户可理解或教学效果已证实。

教学五问：为何值得研究；核心方法；最重要数学结论；关键证明为何成立；相较以前推进什么。
实证无定理时第三问为主要实证结论，第四问为证据如何支持主张，不强造证明。

交付：Markdown可编辑、链接定位可用、图清晰有来源、原稿未改、可恢复、同源重建PDF。
PDF按 [发布规则](pdf.md) 逐页核查；编译仅记built，不记视觉QA通过。
最终限定范围、实际检查、发现、未知、剩余工作；含未知不称全部通过。
同模型自查不支持独立数学正确率认证。

检查应复用证据，而非反复制造同义报告：对完成单元一次核数学与教学，最终核整书接口和交付。
缓存来源、正文、图及检查的哈希；变更时只重查受影响依赖，最终仍核全范围覆盖。
教学义务和90页下限未完成时，下一动作是继续写作，不是打包阶段PDF。
来源暂不可达只让相应数学链保持unverified，不停止其他已具备证据的教学，也不伪造通过。

## 阶段与范围检查

以source→reading-plan→正文→检查记录→最终文件为证据链，逐项核对paper-id、版本、范围、
语言、哈希和资产身份。核心主张没有已读证据、核心图表无处置、正文与检查版本不同，
均不能被“文件齐全/总分高”抵消。正文修改后旧校验失效，按影响重查。

审计的“做了多少”和“发现什么”独立呈现；全部看过但发现错误可以完成审计，
只查了部分且未见错误仍是覆盖不完整。未验证项不靠降级为笔误或not-applicable消失。
回归比较冻结输入、原始产物、提示、工具/模型实际设置与版本；评估前不手修原产物。
没有同条件基线或真实独立评审时，不宣称新版本已经证明更好，保留自查和验证范围。

## 长篇教学验收

对每章核学习目标与先修概念是否就绪，抽取重要定义/公式/证明让读者沿文内链接复核；
每个核心定理及其必要依赖仍需完整检查，教学抽查不替代数学覆盖。对照全书对象索引与
原文/附录，检查分批输出没有丢失单元；核跨章假设、符号、引用与接口。
分别给章级检查与整书状态，某章完成不等于整书完成。长篇PDF逐页检查并绑定页/文件版本。
不以页数短为理由缩写承重推导，不以页数长或目录齐全为理由通过。

按内容检查贯穿例子中间状态是否真的可复算；条件失败例是否指出具体断点；重排的原文/
附录能否反查；教学算例的对象、计算与解释是否完整。用户另行要求练习时再验题解，
不把练习集当默认PDF内容或教学质量证据。涉及算法、近似、数值或实证时，
分别核不变量与返回值、每次近似条件、稳定性与阈值依据、理论/实现与指标口径差别。
简短原理无需填满所有检查项，复杂处则不能因表格齐全而略过正文推导。

## 连贯讲解与PDF边界的阻断项

下列检查记录实际正文位置、发现及修改后的哈希。不能仅凭新增了规则或匹配关键词就记pass。

| 检查 | 不通过的具体表现 | 验收依据 |
|---|---|---|
| 收录边界 | 导航/阅读说明、练习解答或额外研究启发仍在默认PDF，或换名保留 | 比对实际book/input清单、内容与PDF目录/页面；教学算例和必要局限不能误删 |
| 教学顺序 | 只翻译原目录；使用结果早于必要定义/证明且未说明 | 核心依赖与正文次序逐一对应，说明沿用/重排的理由；全量对象仍有落点 |
| 新内容动机 | 新工具或定理突然出现，读者不知道当前困难、自然尝试为何不足及方法效果 | 连读引入段和使用段；自然尝试不得编成作者史实，纯记号可按实际作用简述 |
| 可复算证明 | 构造/常数无来源，矩阵、代入或不等式省掉承重计算 | 核对每个核心证明与必要依赖，重算关键等式、选择和条件；承认不能闭合处 |
| 变量上下文 | 示例/证明直接用未定义符号，跨章换空间或维数无回顾 | 在实际使用处读出对象所属空间、角色与当前约定；末尾索引不能代替解释 |
| 公式与版面 | 只给终式、自由变量无来处；长式缩成难读小字，图注与对象脱离 | 核关键推导的变量就绪、中间步骤与理由；按数学子步骤换行，保持可读字号，核图文邻接、清晰标签、页码和跨章引用 |
| 论述连续性 | 一个对象一个小节，依赖“问题/直觉/证明/总结”标题拼接，合并标题后仍不连贯 | 优先最少必要主章，默认不用三级以下标题；合并同一大问题的碎节并重写过渡，连读完整论证与章间接口 |
| 补写融入 | 因页数不足而在书末加背景/算例/推导新章，原先跳步仍在；新工具先用后教 | 核补写锚点、首次使用与依赖，背景在使用前、推导在原证明中、图例在所解释步骤旁；页数不是新章理由 |
| 内化解释 | 原文翻译/摘录加短评，没有解释中间步骤与推理作用 | 沿自写正文重建核心链，核其具体解释、计算、边界与来源；删掉摘录仍有解释依据 |

原论文缺口可如实保留，不能为了叙事顺畅伪造证明；上述成稿缺陷未修复则教学/交付检查不通过。
局部样例可验证局部行为，不能替代整书连读验收或读者实际评价。
